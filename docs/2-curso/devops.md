# Herramientas y Técnicas DevOps

Apuntes, conceptos y prácticas de la cultura y herramientas DevOps: control de versiones, integración y despliegue continuo (CI/CD), contenedores, orquestación, infraestructura como código (IaC) y monitorización.

---

## 🛠️ Ecosistema y Herramientas

- **Control de versiones:** Git, GitHub, GitLab.
- **Contenedores y orquestación:** Docker, Podman, Docker Compose, Kubernetes.
- **Integración y despliegue continuo (CI/CD):** GitHub Actions, GitLab CI, Jenkins.
- **Infraestructura como Código (IaC):** Ansible, Terraform, Vagrant.
- **Monitorización y observabilidad:** Prometheus, Grafana, Stack ELK / OpenSearch.
