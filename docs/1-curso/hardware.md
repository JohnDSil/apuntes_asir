# Fundamentos de Hardware (FH)

Arquitectura de computadores, componentes internos, periféricos y sistemas de alimentación ininterrumpida (SAI).

---

## 🛠️ Componentes y Almacenamiento

- **Niveles de RAID:**
  - **RAID 0:** Stripping (sin tolerancia a fallos, máxima velocidad).
  - **RAID 1:** Mirroring (espejo, requiere al menos 2 discos, soporta fallo de 1).
  - **RAID 5:** Paridad distribuida (mínimo 3 discos, soporta fallo de 1).
  - **RAID 10:** Combinación de RAID 1 + RAID 0.
